技能与 MCP

角色的能力由两样东西组成：技能按四层来源取，MCP分两段看。实例化时按角色绑定注入，注入后只对那个实例可见，不会漏到别的实例身上。

隔离发生在实例身上。实例化时，插件在它自己的 scope 里注册一份技能清单 —— 只有「内置 + 项目 + 该角色绑定」这三样，全局技能要显式绑进角色才生效。所以 A 实例装了技能，B 实例看不到。

MCP · 两段式

可见范围 = 连接层 ∩ 角色 allowlist
连接层 宿主 / 用户全局配置 · 插件只读，绝不代连
  • dsh-fs 文件读写 已连接
  • git 分支与差异 已连接
  • postgres 只读查询 已连接
  • figma 设计稿取色与标注 未连接
可见层 角色声明 allowlist · 实例只能看到这里面的
  • 实 implementer dsh-fsgit
  • 评 reviewer dsh-fsgitpostgres
  • 需 req-validator dsh-fs figma 未连接

allowlist 里写了但宿主没连的 server 只标灰，不拦着你建角色 —— 连上之后自动生效。反过来，宿主连了但角色没声明的，实例一律看不到。
