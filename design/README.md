# design — 面板 UI 设计稿

> 面板（`main` 插槽里的 myteam 工作台）的 **27 屏 HTML 终稿** + 共用资产。谁要照着实现、对齐或复检面板 UI，先读这里再读屏。
> 这是**设计参照**，不是可执行代码：`plugin/` 源码不 `import`、不构建本目录任何文件；实现真相在 `plugin/client/client.js`。

## 定位

- 27 个 `.html` 是**一屏一个文件**的静态终稿（`file://` 直开，无构建、无依赖），合起来是一套完整信息架构：全局库页 → 项目团队列表 → 团队内看板 / 流程 / 依赖图 → 任务详情 → 各类两段确认与交互态。
- 4 个共用资产（`tokens.css` / `app.css` / `icons.svg` / `dag.js`）被 27 屏共同引用，改一处会同时影响全部屏。
- 设计口径的**正本**是本目录的 [design-notes.md](design-notes.md)（实体模型、作用域分层、插槽落点、视觉映射、已知误报都在那里）；本文件只做索引与纪律，不复述结论。

设计稿与实现的关系是一句话：**设计稿定「长什么样、为什么这么排」，实现定「数据从哪来」**。所以设计稿里的数字一律是演示数据（看板 11 卡 / 3 已完成 / 5 名队员），不构成运行时约定。

## 共用资产

| 文件 | 规模 | 作用 |
|---|---|---|
| `tokens.css` | 108 个设计变量 | 全站唯一色板 / 字号 / 圆角 / 阴影 / 缓动来源。**16 个角色**写成 `var(--dsw-alias-<宿主名>, 本项目原值)` 双通道（浅色 `:root` + 深色整段各 16 条，共 33 处引用）：独立打开走 fallback、嵌进宿主自动跟随宿主主题 |
| `app.css` | 9 章（外壳 / 主区 / 工作台 / 任务详情页 / 成本条 / 通用卡片页 / 弹层 / 会话页 / 响应式） | 27 屏共用的组件样式。只引 `tokens.css` 的变量，不写死颜色；字号下限 12px |
| `icons.svg` | 43 个 `<symbol>` | 图标雪碧图，屏里用 `<use href="icons.svg#i-xxx">`；`.icon` 16px 基准，另有 14 / 18 / 20 三档 |
| `dag.js` | 11 节点 / 13 条边 | 依赖图渲染器：先按真实 DOM 测量节点矩形，再画 SVG 贝塞尔 + `marker` 箭头；`data-layout="h"` 横向 / `"v"` 竖向，层间距 60px、同层间距 16px，画布撑满容器 |

`tokens.css` 里**宿主没有对应物**的四类保留纯字面值，不要硬映射：主色阶（`--primary*` / `--on-*` / `--knob`）、成员四色（`--m1-*` ~ `--m4-*`）、语义色的 `-soft` / `-line` / `-ink` 派生档、尺寸 / 排版 / 阴影 / 缓动。完整映射清单在 `tokens.css` 头注释。

## 怎么看

1. **双击任一 `.html`** 用浏览器打开即可（`file://` 直开，无需构建、无需起服务）。想从入口进就开 `shell.html`（项目）或 `global.html`（全局）。
2. **屏间靠相对链接互跳**：tab、视图条、侧栏、卡片上的入口都是同目录 `href="xxx.html"`，所以**不要移动文件、不要改目录层级**，否则互链与 `icons.svg#i-xxx` 引用会断。
3. `dag.html` / `dag-vertical.html` 额外引 `dag.js`（`<script src="dag.js" defer>`）；依赖图必须脚本跑起来才有连线，纯静态打开看到的是无连线的节点。
4. 每屏头部有 `<meta name="dsh-design" content="web">`，可直接在 DSH 设计工作台里打开预检（`check_design` 量裁切 / 对比度 / 溢出）。
5. 深色看一遍：`tokens.css` 内有 `prefers-color-scheme: dark` 整段换值，浏览器切深色即生效。

## 修改纪律

1. **设计是参照，实现不引用**：`plugin/` 源码（`client/client.js`，单文件、不经 build-lib）不 `import` 本目录、不读这些 CSS；它只消费宿主的 `--dsw-alias-*`。所以改设计稿**不会**自动改实现，改完要人对着改。
2. **改 token 要同时看宿主 alias 回退**：改那 16 个带 `var(--dsw-alias-*, …)` 的角色时，宿主名写错在**独立打开时看不出来**（走 fallback），只有嵌进宿主才变色——改完必须两种打开方式各验一遍。防回归断言是 `plugin/test/t82-design-tokens.test.ts`。
3. **27 屏是终稿**：任何屏幕级改动先登 CHG（[../docs/09-变更记录.md](../docs/09-变更记录.md)），再改 HTML。不要顺手「统一重排」——CHG-84/85 已逐屏复检过（79 处差异 + 7 处真实裁切），重排会把这些结论作废。
4. **颜色只从 `tokens.css` 取**：屏里不写十六进制、不写 `font-family`（宿主统一字体栈）。深色模式是 `prefers-color-scheme` + `[data-theme]` 双通道，改色两处都要看。
5. **已知误报不要为消警改样式**：固定底栏 `.costbar`、滚动容器内元素（含未滚到可视区的盒子）、`.scrim` 弹层与其下方看板、`dragging.html` 的悬浮卡与其覆盖内容，会被自动检查报成「文字叠在一起」。已逐屏目视确认无问题，改动前先看 [design-notes.md](design-notes.md) §九「已知检测误报」。
