## 2. 实现中的关键决策（均已进 ADR/任务板，摘要）

1. **claim 语义**：backlog+deps 全 done 等价 ready（fold 在 claimed 时推进，角色/优先级校验在 service 层）——发现并修正了"创建后无人推进 ready"的空档。
2. **gate 链配置驱动**：转移表只列骨架，gate 间后继由任务 `gateChain` 动态判定（FR-10.3 通用性）。
3. **队长提示词载体**：preset 内用 `dsh-persona` 行（scope-only，全局挂载会 fail loud）——T0 探针后修正。
4. **默认 columnMapping 必须覆盖全部终态**（failed/blocked/cancelled 归并入 backlog 列头下的"需人工"分区）——否则默认配置自身触发回退告警。
5. **合并语义两分**：对象段落按子键合并（保留默认键）、数组整条替换（K5）——修复了"部分覆写 columnMapping 丢默认键"问题。
6. **证据块校验双重**：结构校验（validateEvidenceBlock）+ done 时序校验（当前 attempt 必须已有 evidence 事件）。

## 5. 回滚方案

- 账本只追加不覆盖：任何阶段回滚 = 代码回退 + 删除 `.team-workplace/state/teams/<id>/`（状态可从账本重建，账本本身是唯一权威）。
- gitignore 托管块：删除两行标记块即退出干净（不碰用户规则）。
- 插件卸载：dsh.profile.bundles 移除即可（无全局状态残留；`$DSH_HOME/myteam/roles/` 为用户资产不清理）。
