## 边界

- `architecture/` 回答系统为什么这样划分，以及跨功能不变量；
- `product/` 回答目标用户与需求；
- `features/` 回答每个功能如何实现；
- `contracts/` 回答稳定接口与机器契约；
- `audits/` 回答代码或真机实际验证过什么。

后续局部架构取舍放入 `decisions/`，每份 ADR 只处理一个主题，并明确 `accepted/superseded` 关系，不再把多轮决策持续追加到一份总文档中。
