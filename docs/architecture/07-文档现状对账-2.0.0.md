## 1. 判据

一条文档断言算「成立」，必须能指到下面四类证据之一：

| 证据类型 | 出处 | 能证明什么 |
|---|---|---|
| 代码 | `plugin/src`（65 个模块）、`plugin/client` | 能力存在，且分层门禁通过（`tools/check-architecture.mjs`） |
| 生成契约 | `docs/contracts/{panel-rpc,tool-surface,config-schema,capabilities}.md`（`tools/gen-*.mjs`） | 接口面与代码一致，不需要手改 |
| 测试 | `plugin/test`（文件数见 §2，不在这里重复） | 行为可复现；由 `tools/verify.mjs` 统一跑 |
| 真机 | `docs/audits/`、[25-隔离验收记录](../delivery/25-隔离验收记录.md) | 在真实宿主里跑通过（隔离实例 46/46、真实模型回合一整轮） |

反过来：文档里出现「proposed / 待实现 / 仍是旧 Runtime」这类断言时，只要上面四类证据显示已成立，
它就是**过期断言**，必须在本轮重写里改掉，不能继续当评审前提。
