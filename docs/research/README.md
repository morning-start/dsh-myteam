使用原则：

1. 标明来源和时点，不把外部项目能力当作本机 DSH 已验证能力；
2. 新架构决策必须回到 `architecture/` 评审；
3. 历史建议与后续决策冲突时，在新架构中明确 superseded，而不是修改研究结论伪装一致。
