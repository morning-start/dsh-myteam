## 写法

每条按固定形状，缺一项就等于没记：

```markdown
## N. <短标题>
- Saw: <让这一步成为下一步的状态>
- Decided: <为什么做这一步，它能证明什么>
- Did: <碰了哪些文件、跑了哪些命令>
- Evidence: `<命令>` → <结果，退出码>
- Outcome: done | dead end | unverified
```

死路要记命令和输出，否则下一轮会把同样的坑再踩一遍。
