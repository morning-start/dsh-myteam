## M2 重规划（CHG-39，2026-10-31，依据「分析当前系统架构」会话实测 + PM 复核）

> **触发依据（三条实锤，均已 PM 复核）**：
> ① **KI-14 是 P1 实弹阻塞**：成员会话 LLM 驱动在 headless CLI 下 turn 空转（turns 增长、llmMs=0、prompt=""）；队长同代码路径正常 ⇒ 判定宿主 factory 通道（`agents.create`）在 headless 进程模型的驱动语义问题。**成员跑不起来，团队核心价值不成立** —— 这是方案三（插件持有会话）的成立前提。
> ② **ADR-002 承诺未实现**：ADR 写「team.json 原子落盘 + 损坏可重建」，代码零写入（`service.ts:116` 每次 commit `foldEvents` 全量重放），`src` 无任何 team.json 写路径 ⇒ O(n²) 提交 + 缓存加速承诺落空。
> ③ **src/lib 双份来源无门禁**：`main` 指向 `lib/host.mjs`，改 src 忘 bundle 则装载跑旧产物；当前实测一致但无 CI/测试守住。
>
> **结论：M2-UI 从「立即开工」降为「地基验证后开工」**。理由：UI 的每一屏都在展示成员产出（看板卡、详情证据、成本归因、审计回放），若成员不产生任何 LLM 产出，UI 只能展示空壳——**先验证地基，再上视觉**。
