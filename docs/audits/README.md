验证纪律：

- 静态代码推导、单元测试、真机实测分别标注，不能互相冒充；
- 测试计数以本次命令结果为准，不复制旧会话数字；
- 新架构验收应产生新的审计文档，不回填旧报告；
- UI 证据与设计稿问题不直接决定领域模型。
