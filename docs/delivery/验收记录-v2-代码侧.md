## 发现并修复的真问题（真机暴露）

1. 项目根取 `process.cwd()` → 多工作区接错项目；改为 `workingDirectory.ensure(agent)` + `inject` 声明；
2. 队长/成员各自打开运行时 → 租约互斥；改为进程级按 root 共享（引用计数）；
3. 权限表漏 `task.review` / `task.complete` → 队长无法裁决完成；
4. 成员用 `agents.create` 建后不执行（只有 session 头）→ 改 `subagents.startActivation`；
5. 写者租约无续租 → 空闲 >60s 后首次写入失败；
6. 面板门面找不到 `@deepseek-ai/dsh-typert-protocol` → 从 `DSH_INSTALL_DIR` 解析；
7. 客户端未声明 `inject: ['slots']` → 视图注册被 Cordis 拒绝。
