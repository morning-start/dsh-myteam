环境：新建 profile `myteam-v2-web`（从 web 模板），`link:` 到本分支插件，`dsh --profile myteam-v2-web --port 5199 --no-open`，loopback token 访问。

| 检查 | 结果 |
|---|---|
| 团队模式 / 团队成员 preset 出现在模式菜单 | ✅ |
| 队长工具在真宿主里可调用 | ✅ `myteam_read_board` 返回 `{"ok":true,...}`（空项目自动建 v2 manifest） |
| v1 数据闸门 | ✅ 返回 `MANIFEST_INVALID`（拒绝静默升级） |
| 项目根来源 | ✅ 取**会话工作目录**：实例 cwd 在 worktree，错误路径指向会话所属工作区 |

发现并修复：项目根原先取 `process.cwd()`，多工作区会接错项目；现改为 `workingDirectory.ensure(agent)`，并在 `inject` 中声明 `agents`/`workingDirectory`（未声明时 Cordis 直接拒绝访问）。
