## 0. 起一个**隔离**的 web 实例（不碰桌面端、不抢会话）

```powershell
tools\boot-iso-web.cmd            # 首次会建 profile + 装插件 + 播一份工作区副本，之后直接起在 3099
tools\boot-iso-web.cmd 3104       # 想换端口
```

> 它会自动准备 `tmp\shot-ws`（仓库狗粮项目的副本，含甲队与任务）。打开打印出来的
> `http://127.0.0.1:<port>/?token=…`；`Ctrl+C` 只停这个实例。

### 想自己复跑自动截图（可选）

会话「团队视图」的截图现在是**机器点的**，配方（脚本在 `.debug/`，本机临时产物）：

1. `tools\boot-iso-web.cmd 3099` 起隔离实例，记下打印的 `?token=…`。
2. `node .debug/iso-new-session.mjs <日志> "<标题>"`：用宿主自己的 `session/create` +
   `session/prompt` 造一个**有首条消息**的会话 —— 空会话不进左栏，有消息才有标题、才有会话级标签页。
   它不需要模型成功（隔离 home 没 key，回合会报 `MISSING_CREDENTIAL`，用户消息照样留下）。
3. `.debug/iso-tidy.mjs`：`workspace/unarchiveSession` + `session/rename` + `workspace/pinSession`，
   把标题改成想显示的（走宿主 RPC，**不手改** `storages/workspace.json`）。
4. **Chrome headless + CDP**（`--headless=new --remote-debugging-port=9222`），
   `node .debug/cdp4.mjs .debug/scn-teamview-final-shot.mjs "http://127.0.0.1:3099/?token=…"`
   → 点左栏会话行 → 点会话级「团队视图」→ 浅色 / 深色 / 414px 各截一张到 `.debug/shots/`。

> 走这条路是因为：会话标签页只在**进了会话之后**才渲染；而空会话不进左栏、工作区选择器是
> 原生目录对话。用「RPC 投一条消息」绕过前一条，就不需要人点了。

它为什么不会和桌面端打架（三个都分开，缺一不可）：

| 维度 | 桌面端 | 本测试实例 |
|---|---|---|
| `DSH_HOME` | `~/.dsh`（会话、storages、凭据、`myteam/`） | `tmp/iso-home`（全新建，互不可见） |
| profile | `desktop` | `iso-myteam`（从 `web` 模板复制 + 本仓库插件 `link:`） |
| 端口 | 桌面端自己那个 | `3099`（显式绑定） |

> 凭据：隔离 home 里的 `.credentials.yaml` 是空的，所以这个实例**不能调模型**
> （面板读写都不需要模型）。要在里面跑 agent 建队，就把 `~/.dsh/.credentials.yaml`
> 复制到 `tmp/iso-home/`，或在该实例的设置里配一次。
>
> 反例：不要再从脚本里起 `DeepSeek Harness.exe … dsh-desktop-host\cli.js`——那是桌面端
> 自己的进程，会把正在用的桌面端顶掉（这几轮崩溃就是这么来的）。

## 1. 左栏入口（全局库）

1. 左栏应出现 **myteam**（在「插件 / 自动化任务」下面）。
2. 点它 → 右侧出现「全局库」：左导航五栏 = 概览 / 角色 / 工作流 / 蓝图 / 发布。
3. 概览应有 `条目 n` 与 `$DSH_HOME/myteam` 路径；角色栏应看得到已发布的角色。

> 期望文案：页头作用域写「**全局** · <栏名>」，不是「项目」。

## 2. 会话「团队视图」（核心，已自动点过一遍，见 25 的三张图）

1. 左栏 `shot-ws` 分组里点一个**有标题**的会话（隔离 home 已经注册好这个工作区；
   自己没有会话就先按上面「复跑自动截图」第 2 步造一个）。
2. 会话顶栏应出现 **团队视图** tab（不是「项目」）。点开。
3. 页头：作用域「**团队视图** · <栏名>」，右上刷新按钮可点。
4. 逐栏切：概览 / 任务 / 团队 / 流程 / 定义 / 知识 / 记忆 / 审计 / 设置。
   - 每栏都要么有真实数据，要么明确的空状态文案（如「这个项目还没有事件」）。
   - **不允许**出现：「通道未接入」、一直「读取中…」、整块空白。
5. 概览：团队卡片应显示甲队（成员/任务计数）；看板计数与「n 个任务」一致。

## 3. 写交互长什么样（看得到表单即可，未必要提交）

1. 任务栏右下「新任务」→ 出现表单（标题必填、验收标准一行一条）。
   - 提交后看板立刻多一张卡（会写进 `events/project.jsonl`，介意就别点提交）。
2. 任务栏点任意卡片 → 任务详情；仅 `review` 状态显示**门禁裁决**表单（通过/驳回 + 检查结果）。
3. 团队栏选中团队 →「解散团队」：**第一次只出影响面**（成员/未完成任务/未结效果），
   第二次才执行。**只看不确认**就等于没执行。
4. 定义栏「发布」→ 预览引用与覆盖 → 确认（会写 `$DSH_HOME/myteam/`）。

## 4. 主题与窄宽（已量过：对比度 5.8 起、414px 无越界；愿意复看就照下面来）

1. 宿主切深色主题：面板文字/边框/状态点仍可读，没有白底黑字的块。
2. 窗口拉窄到约 900px（再把浏览器缩到手机宽度试一次）：
   - 不能出现横向滚动条、文字被裁、按钮叠在一起；
   - 计数卡在 760px 以下退成两列，团队卡退成一列是**预期**的；
   - 看板 8 个状态列会折成两排（设计稿只画了 5 列），可以接受，但不能互相压字。
