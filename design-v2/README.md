## 这一版的规则

- **外壳不出槽位**：不画 DSH 侧栏、会话顶栏、右栏；插件只活在 `[data-slot="main"]` 里，弹层也画在里面。
- **一层导航**：68px 图标轨（图标 18 + 12px 标签），5 项 = 任务 / 角色 / 知识 / 审计 / 设置；视图（看板 / 列表 / 流程 / 依赖图）是工具条里的 seg，不进导航。
  - 为什么不沿用 220px 文字轨：1000 宽里再切掉 220，五列每列只剩 140px，卡片标题与标签必然折断。68px 轨把内容宽度还给看板（932 → 每列 172px）。
- **一屏一个焦点**：页头 = 团队名 + 状态 + 切换团队；下面是计数摘要；工具条右侧永远只有「筛选 + 一个主操作」。
- **字号四档**：12 / 13 / 14 / 16，不再出现 10px、11px。
- **中性两档**：`--dsh-fg` 与 `--mt-muted`（`#5c6167`，白底 6.2:1、灰底 5.0:1）；状态只分「进行中 / 待裁决 / 已完成 / 空闲」四色，且**文字永远写状态名**，颜色只做第三通道。
- **卡片就是白底 + 1px 线 + 10 圆角**，没有阴影堆层级；唯一的浮层是确认弹层。
- **深色**：`<html data-theme="dark">`，`--dsh-*` 与 `--mt-*` 都给了深色值。

## 怎么看

1. 双击任一 `.html`；入口是 `teams.html`（左侧栏「团队」那一行）或 `board.html`（团队工作台）。
2. 屏间靠相对链接互跳（导航轨、seg、卡片、面包屑）；不要移动文件或改目录层级，否则互链会断。
3. `dag.html` 末尾有一小段脚本负责画连线（按节点真实 DOM 位置算贝塞尔），删了脚本就只有节点没有箭头。
4. 深色：浏览器切换深色模式，或给 `<html>` 加 `data-theme="dark"`。

## 和 `../design/` 的关系

- `../design/`（28 屏）是上一版：整页面板 + 五个功能域 tab + 底部成本条 + 76px 成员头像轨，token 走 `--dsw-alias-*` 映射。
- 本目录是重写版：**只用两个插件位置**，外壳不出槽位，视觉完全跟宿主；团队目标、成本、成员在场都收进页头与页脚的一行摘要里。
- 不变的：实体口径（角色 = 唯一实体，成员 = 聘任记录）、状态机、两段确认、证据优先、成本一律标「估算」。这些仍以 `../design/design-notes.md` 为准。

## 已知
